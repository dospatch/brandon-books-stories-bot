# Official Book Cover Assets

The repository currently contains no official cover image files for the seven books. The bookstore therefore uses clearly labeled placeholders rather than invented artwork.

Please provide the official front-cover image for each book. Suggested filenames:

- `assets/book-1-cover.jpg`
- `assets/book-2-cover.jpg`
- `assets/book-3-cover.jpg`
- `assets/book-4-cover.jpg`
- `assets/book-5-cover.jpg`
- `assets/book-6-cover.jpg`
- `assets/book-7-cover.jpg`

Use the actual front cover artwork, ideally a high-resolution portrait image. JPG or PNG is suitable for the web; WebP can be generated as an optimized derivative after the original is preserved.

Do not recreate, retouch, crop, recolor, or replace the cover text without the author's approval. Do not use generated covers or unverified retailer images as official artwork.

When the author supplies the files, add them to the website assets, update the seven catalog cards and detail pages, and test the image dimensions and mobile rendering.
